この記事のポイント

- 動物病院の問診票が尋ねる項目（最後に食べた日、餌の種類と量、脱皮、排せつ、温度と湿度、サプリや薬）が、記録する項目の手がかりになります。
- 体重は「週 1 回」か「月 1 回」に決めて、同じはかりで量ります。幼い個体は増え、成体は保たれるのがふつうです。
- 新しく迎えた個体は別にし、世話はいちばん最後に。道具を分け、触ったあとは手を洗います。

## 動物病院が尋ねることを、記録しておく

米国の大学附属動物病院の爬虫類の問診票は、飼い主に次のようなことを尋ねています <a class="cite" href="#src-1">[1]</a>。

- ふだんの食事（餌の種類と量）、直近 2 週間の食事の変更、最後に食べた日
- 飲水・排便・排尿がふだんどおりか、脱皮がふだんと違うか
- 直近 2 週間に使った薬とその用法、ビタミンやサプリと量
- 単独で飼っているか、同居や接触する動物がいるか
- ケージの掃除の頻度と使う洗剤、床材、ケージ内の最高温度と最低温度、UVB ランプの銘柄とワット数
- 直近 2 週間の環境の変化やストレスになる出来事

VCA グループの動物病院の問診票も、最後に脱皮した日とその脱皮がふだんどおりだったか、暖かい側と涼しい側の温度、湿度、サプリの種類と頻度などを尋ねています <a class="cite" href="#src-2">[2]</a>。

こうした項目を、残すタイミングで分けると次のようになります。

| いつ | 残すこと |
| --- | --- |
| 給餌のたび | 日付、餌の種類・大きさ・数、食べたか（拒食か） |
| 決めた間隔で | 体重（グラム）、脱皮した日とうまく脱げたか、便や尿酸の様子 |
| 変えたとき | 温度・湿度（暖かい側と涼しい側）、照明や UVB ランプの交換、サプリの種類と頻度、通院と薬、レイアウトや同居の変化 |

環境省の販売業者向けのマニュアルは、爬虫類は適切でない環境でもかなりの期間生きることがあり、何年もかけて少しずつ弱っていくこともあるので、日ごろの観察がとても大切だとしています。温度は目に見えないため、最高最低温度計は欠かせない装備だとも書いています <a class="cite" href="#src-3">[3]</a>。

## 体重を量る頻度

- 動物福祉団体の RSPCA（オーストラリア）は、行動・食欲・糞・体重を少なくとも週 1 回確かめ、体重は週 1 回か月 1 回量るよう勧めています。幼い個体は着実に増え、成体は保たれるのがふつうで、急な減少も、じわじわした減少も気にかけるべき変化だとしています <a class="cite" href="#src-4">[4]</a>。
- 飼育ガイドの ReptiFiles は、ボールパイソンは毎週 <a class="cite" href="#src-5">[5]</a>、コーンスネークは月 1 回量り、給餌の間隔を決めたり、成長や体重の減少をつかんだりするのに使うよう書いています <a class="cite" href="#src-6">[6]</a>。
- どれだけ減ったら気にかけるかは、資料によって違います。ReptiFiles はボールパイソンで「体重の 10% を超える減少」を挙げています <a class="cite" href="#src-5">[5]</a>。種ごとの見方は、[レオパの給餌の記事](/guide/leopard-gecko-feeding-ja)と[ボールパイソンの拒食の記事](/guide/ball-python-refusing-food-ja)にまとめています。

何匹もいる場合は、量る曜日を決めて、全員を同じはかりでまとめて量ると、続けやすく、比べやすくなります。

## 個体ごとに分けて残す

- 名前、種、性別とその判定方法、迎えた日と入手先は、問診票でも尋ねられる基本の情報です <a class="cite" href="#src-2">[2]</a>。
- 環境省のマニュアルは、レオパは大きさや模様で見分けられるが模様は変わるので、毎月 1 回など忘れにくい習慣で確かめるとよい、と書いています <a class="cite" href="#src-3">[3]</a>。模様の分かる写真を、ときどき撮り直しておくと役立ちます。
- 飼育者のフォーラムでは、1 匹ごとのノート、スプレッドシート、アプリなどが使われ、ケージに QR コードを貼ってその個体の記録を開く人もいます。規模が大きくなると手書きは時間がかかりすぎる、という声もあります <a class="cite" href="#src-7">[7]</a>。

## 同居させるなら、給餌は個別に

多くの資料は、1 匹ずつ別のケージで飼うことを基本にしています <a class="cite" href="#src-8">[8]</a> <a class="cite" href="#src-3">[3]</a>。ここで引く飼育ガイドも、どの種でも同居を勧めていません <a class="cite" href="#src-9">[9]</a> <a class="cite" href="#src-10">[10]</a> <a class="cite" href="#src-11">[11]</a>。以下は、同居させる場合の注意として読んでください。

- レオパ：オス同士は分ける <a class="cite" href="#src-3">[3]</a>。飼育ガイドの ReptiFiles は、メス同士でもけがが起きうるとして、同居そのものを勧めていません <a class="cite" href="#src-9">[9]</a>。
- クレステッドゲッコー：オス同士は争う。性別の分からない幼い個体を一緒に育てたら、どちらもオスに育ち、1 匹が死に、もう 1 匹が大けがをした例がある <a class="cite" href="#src-10">[10]</a>。
- フトアゴヒゲトカゲ：成体のオスは 1 ケージに 1 匹 <a class="cite" href="#src-12">[12]</a>。
- コーンスネーク：同居させるなら、給餌は必ず別々に、ケージの外で <a class="cite" href="#src-11">[11]</a>。
- キングスネーク：大きい個体と小さい個体を一緒にしない（小さい個体を食べるおそれ） <a class="cite" href="#src-13">[13]</a>。

レオパを同居させる場合、置き餌は強い個体が独占しやすいため、ピンセットで個別に与えるよう勧める記事もあります <a class="cite" href="#src-14">[14]</a>。個別に与えると、誰が何をどれだけ食べたかを個体ごとに残せます。同居している個体の体重の減少や食欲の低下は、同居のストレスのサインになりうるとされています <a class="cite" href="#src-10">[10]</a> <a class="cite" href="#src-11">[11]</a>。

## 新しく迎えた個体：検疫と世話の順番

新しく迎えた個体は、ほかの個体と離してしばらく様子を見ます（検疫）。期間の目安は資料によって違います。

| 資料 | 検疫の期間 |
| --- | --- |
| VCA（米国の動物病院チェーン） <a class="cite" href="#src-15">[15]</a> | 新しいヘビは 1 か月 |
| 動物病院の資料 <a class="cite" href="#src-16">[16]</a> | 最低 90 日（大きな動物園の目安に合わせる） |
| Merck Veterinary Manual（獣医師向けの専門書） <a class="cite" href="#src-8">[8]</a> | 3〜6 か月 |
| ReptiFiles（飼育ガイド） <a class="cite" href="#src-17">[17]</a> | 3〜6 か月（ニシキヘビの仲間は約 12 か月という注記あり） |
| 環境省のマニュアル <a class="cite" href="#src-3">[3]</a> | 日数の記載なし。新しい動物を入れるときは十分な検疫を設けることが第一 |

世話の順番と道具の分け方は、獣医師の資料と飼育ガイドで、ほぼ一致しています。

- 触る・餌をやる・掃除する、のどれも、健康な既存の個体を先に、検疫中の個体を最後にします <a class="cite" href="#src-16">[16]</a> <a class="cite" href="#src-18">[18]</a> <a class="cite" href="#src-19">[19]</a> <a class="cite" href="#src-17">[17]</a>。
- 水入れ、ピンセット、温度計、霧吹きなどの道具を共用しません <a class="cite" href="#src-16">[16]</a>。検疫中の個体ごとに、掃除・給餌の道具をそろえるよう勧める病院もあります <a class="cite" href="#src-18">[18]</a>。
- 検疫中の個体が食べ残した餌を、ほかの個体に回しません <a class="cite" href="#src-16">[16]</a>。
- ヘビは 3〜4 回続けて食べるまで検疫を終えないよう勧める病院もあります。同じ病院は、新しく迎えたすべての個体について、体重を定期的に確かめ、寄生虫の検査用の便を少なくとも 2 回出すよう勧めています <a class="cite" href="#src-16">[16]</a>。

検疫の間は、始めた日、体重、食べた回数、便の検査の日を残しておくと、検疫を終えてよいかの判断に使えます <a class="cite" href="#src-16">[16]</a>。迎えたら 2 週間以内に健康診断を受け、その後も少なくとも年 1 回受けるよう VCA は勧めています <a class="cite" href="#src-20">[20]</a>。

## 手洗いと家の中の衛生

- 爬虫類は、健康に見えてもサルモネラ菌を持っていることがあります <a class="cite" href="#src-21">[21]</a>。厚生労働省は、カメなどの糞便の検査で保菌率が 50〜90% だったという国内外の報告を紹介しています <a class="cite" href="#src-22">[22]</a>。
- 餌やり、掃除、体に触ったあとは、石けんと流水で手を洗います <a class="cite" href="#src-21">[21]</a> <a class="cite" href="#src-22">[22]</a>。
- 台所のシンクで器具を洗ったり、冷凍マウスを解凍したりしません。電子レンジでの解凍も避け、冷凍の餌は人の食品と分けておきます <a class="cite" href="#src-21">[21]</a>。
- 米国疾病予防管理センター（CDC）は、5 歳未満の子ども、65 歳以上の人、免疫の弱い人がいる家庭には、爬虫類を勧めていません <a class="cite" href="#src-21">[21]</a>。
- おなかの具合が悪くて医療機関にかかるときは、爬虫類を飼っていることを伝えます <a class="cite" href="#src-23">[23]</a>。

## 受診のときに持っていくもの

- 新しい便。米国の大学附属動物病院の問診票は、湿らせたペーパータオルで包んで密閉できる袋に入れ、冷蔵して 24 時間以内に持ってくるよう案内しています <a class="cite" href="#src-1">[1]</a>。
- 飼育の記録（温度・湿度など）、ケージ用の温度計、動きや呼吸の様子を撮った写真や動画 <a class="cite" href="#src-24">[24]</a>
- 使っている薬やサプリの情報（薬の飲み合わせの確認に使われます） <a class="cite" href="#src-24">[24]</a>

記録がそろっていると、問診票の「最後に食べた日」「直近 2 週間の変化」にもすぐ答えられます。
