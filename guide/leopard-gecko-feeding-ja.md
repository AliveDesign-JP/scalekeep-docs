<div class="points" markdown="1">
この記事のポイント

- 幼い個体ほど回数を多く、成体ほど少なく。この向きはどの資料でも同じですが、成体の間隔は「1 日おき」から「5 日ごと」まで分かれます。
- 間隔は日数だけで決めず、尾の太さや体型を見て調整するよう書く資料があります。体重を量って記録すると、その判断に使えます。
- 食べない日が続くときは、日数だけでなく、体重・尾の太さ・元気・便などの変化もあわせて見ます。何日で相談するかの目安も、資料によって 2 日から約 2 週間まで分かれます。

## 年齢別の給餌の間隔

獣医師が書いた資料や飼育ガイドの目安を並べると、次のようになります。

| 資料 | 幼い個体 | 成体 |
| --- | --- | --- |
| 米国の動物病院チェーン VCA（獣医師） <a class="cite" href="#src-1">[1]</a> | 1〜2 日ごと | 週 2〜3 回 |
| PetMD（獣医師の執筆） <a class="cite" href="#src-2">[2]</a> | 毎日 | 1 日おき |
| 米国の動物病院の飼育シート <a class="cite" href="#src-3">[3]</a> | 毎日 | 1 日おき（太っていればさらに少なく） |
| 日本の動物病院のブログ <a class="cite" href="#src-4">[4]</a> | 記載なし | 週 3 回程度 |
| ReptiFiles（飼育ガイド） <a class="cite" href="#src-5">[5]</a> | 毎日 | 若い成体は 1 日おき〜3 日ごと、尾が首より太い成体は 5 日ごと |

成体になる時期の区切り方も資料ごとに違い、「3 か月まではベビー、1 歳からアダルト」と月齢で分けるもの <a class="cite" href="#src-6">[6]</a>、「1〜2 年で成体になる」とするもの <a class="cite" href="#src-2">[2]</a>、尾の太さ（体型）で分けるもの <a class="cite" href="#src-5">[5]</a> があります。体重のグラム数で区切った資料は、今回調べた範囲では見つかりませんでした。

どの資料にも共通するのは、成長期は回数を多く、成体になったら減らすという向きです。具体的な日数は、迎えたときの購入元の与え方や上の目安から始めて、後の「体型の見方」と体重の記録を見ながら調整していくことになります。

## 1 回の量と餌の大きさ

- 量は、15 分ほどで食べきれる分を目安にする資料があります <a class="cite" href="#src-5">[5]</a>。食べなかった虫は 10〜15 分で取り除く <a class="cite" href="#src-7">[7]</a>、虫をケージに放したままにしない（寝ている間にかまれるおそれがある）という注意も共通しています <a class="cite" href="#src-3">[3]</a> <a class="cite" href="#src-5">[5]</a>。
- 餌の大きさの基準は、「両目の間の幅より大きくしない」 <a class="cite" href="#src-2">[2]</a> <a class="cite" href="#src-3">[3]</a>、「長さは頭の長さまで、幅は頭の幅の半分まで」 <a class="cite" href="#src-7">[7]</a>、「最大でも頭の幅まで」 <a class="cite" href="#src-8">[8]</a> と、資料によって違います。両目の間の幅がいちばん小さい基準です。

## 主食とおやつ

- 主食はコオロギやデュビア（餌用のゴキブリ）などで、ワックスワーム・スーパーワーム・バターワームのような脂肪の多い虫はおやつとして控えめに、とする資料があります <a class="cite" href="#src-2">[2]</a> <a class="cite" href="#src-3">[3]</a> <a class="cite" href="#src-5">[5]</a>。ミルワームは、主食の候補に入れる資料 <a class="cite" href="#src-5">[5]</a> と、控えめにする資料 <a class="cite" href="#src-3">[3]</a> に分かれます。
- 野外で捕まえた虫は与えない <a class="cite" href="#src-7">[7]</a> <a class="cite" href="#src-5">[5]</a>、果物や野菜はレオパには与えない <a class="cite" href="#src-5">[5]</a>、とされています。
- 餌の虫は、与える前に栄養のある餌を食べさせておく（ガットローディング）よう勧められています。時間は「少なくとも 24 時間前から」 <a class="cite" href="#src-1">[1]</a> などです。虫はもともとカルシウムが少なくリンが多いため、補う必要があるとされています <a class="cite" href="#src-9">[9]</a> <a class="cite" href="#src-4">[4]</a>。

## カルシウムと D3

- 餌の虫はカルシウムが少ないため <a class="cite" href="#src-9">[9]</a> <a class="cite" href="#src-4">[4]</a>、カルシウム剤を虫にまぶして与えるのが基本です <a class="cite" href="#src-1">[1]</a> <a class="cite" href="#src-5">[5]</a> <a class="cite" href="#src-10">[10]</a>。
- 回数は資料で大きく分かれます。カルシウムは毎回まぶすとする資料がある一方 <a class="cite" href="#src-5">[5]</a> <a class="cite" href="#src-10">[10]</a>、ビタミン D3 を含む製品は「D3 入りのカルシウムを週 2〜3 回」 <a class="cite" href="#src-3">[3]</a> から「D3 を含む総合ビタミン・ミネラル剤を 3 週おき」 <a class="cite" href="#src-10">[10]</a> まで、大きな差があります。
- 差が出る理由の一つは、UVB ライトを使っているかどうかです。適切な UVB があれば D3 入りの回数は減らせるとする資料があります <a class="cite" href="#src-2">[2]</a> <a class="cite" href="#src-5">[5]</a>。D3 は与えすぎも害になるとされています <a class="cite" href="#src-10">[10]</a>。
- サプリの使い方は獣医師に相談するよう勧める資料もあります <a class="cite" href="#src-7">[7]</a>。

## 体型の見方（尾の太さ）

レオパは尾に脂肪をためます <a class="cite" href="#src-11">[11]</a>。体型の目安は次のとおりです。

- 健康な個体は、尾の脂肪の幅が体の幅に近い <a class="cite" href="#src-12">[12]</a>。
- やせ始めると、まず尾の脂肪が減ります。しっかり丸かった尾が、細い棒のようになっていきます <a class="cite" href="#src-11">[11]</a>。背骨・腰の骨・肋骨が目立つのも、やせのサインです <a class="cite" href="#src-12">[12]</a>。
- 太りすぎのサインは、尾が体より太い、首の下にたるみがある、背中やわき腹の脂肪で背骨や肋骨が触れない、などです <a class="cite" href="#src-12">[12]</a>。太っている個体は給餌の回数を減らすよう勧められています <a class="cite" href="#src-3">[3]</a>。

## 食べなくなる、よくある理由

病気でなくても、次のようなときには食欲が落ちることがあります。

- 脱皮の前後 <a class="cite" href="#src-6">[6]</a>
- 冬や、ケージの温度が低いとき（代謝や消化の働きが落ちる） <a class="cite" href="#src-13">[13]</a> <a class="cite" href="#src-6">[6]</a>
- 繁殖期（オスは気が散って数週間食べないことがあり、メスはホルモンや体の変化で食べないことが多い） <a class="cite" href="#src-13">[13]</a>
- 迎えたばかり、同居の個体がいる、大きな音や強い光がある、などのストレス <a class="cite" href="#src-13">[13]</a>
- 与えすぎで、おなかがすいていない <a class="cite" href="#src-13">[13]</a>

飼育ガイドの ReptiFiles（著者は獣医師ではありません）は、繁殖期や冬の低温期には数週間〜数か月食べないこともあり、体重がおおむね保たれていれば問題ないとしています <a class="cite" href="#src-5">[5]</a>。一方で、動物病院の症例には、3 週間ほど食べなかったメスのおなかに卵（卵胞）がたまり、排卵がうまくいっていなかった例もあります。このときは尾が細くなりつつあり、おなかが張っていました <a class="cite" href="#src-14">[14]</a>。メスが食べないときは、おなかの張りや尾の細りがないかも見ておきます。

## 何日食べなかったら相談するか

ここは資料による差がいちばん大きいところです。

| 資料 | 目安 |
| --- | --- |
| 日本の動物病院 A <a class="cite" href="#src-10">[10]</a> | 「食欲が 2 日以上ない」を、脱皮の不調や便の異常と並ぶ受診の目安に挙げる（年齢の区別なし） |
| 日本の動物病院 B <a class="cite" href="#src-15">[15]</a> | 「3 日以上の絶食で来院を検討」（年齢の区別なし） |
| 獣医師が確認した一般向けメディア <a class="cite" href="#src-13">[13]</a> | 約 2 週間食べなければ獣医師に連絡。元気がないなど、ほかの症状があればすぐに |
| 海外の獣医師の資料 <a class="cite" href="#src-2">[2]</a> <a class="cite" href="#src-7">[7]</a> <a class="cite" href="#src-3">[3]</a> | 日数の目安は示さず、食欲の低下そのものに加えて、体重の減少、尾の細り、元気がない、目の腫れ、おなかの腫れ、下痢などを受診のサインに挙げる |
| 個人の飼育サイト <a class="cite" href="#src-6">[6]</a> | 健康な成体は 2 週間以上続いたら相談。ベビー・ヤングは 1 週間以内が理想 |

日本の動物病院 A は、ヤモリの仲間は飢えに強いため、目に見える症状が出たときには重くなっていることが多い、とも説明しています <a class="cite" href="#src-10">[10]</a>。

資料の数字はばらばらですが、共通しているのは、日数だけで決めないことです。

- 体重が減っている、尾が細くなってきた、元気がない、便の様子がいつもと違う、おなかが張っている。こうした変化があれば、日数にかかわらず相談を考えます <a class="cite" href="#src-2">[2]</a> <a class="cite" href="#src-7">[7]</a> <a class="cite" href="#src-3">[3]</a> <a class="cite" href="#src-10">[10]</a>。
- 食べないからといって、自己判断で無理に口に入れるのは避けるよう、動物病院が注意しています（誤って気管に入ったり、詰まったりするおそれ） <a class="cite" href="#src-15">[15]</a>。

## 体重を量って記録する

- 英国の獣医師は、毎週体重を量ると、ほかのサインが出る前に問題に気づけるとしています <a class="cite" href="#src-11">[11]</a>。ReptiFiles も、体重・食べ方・行動・脱皮を毎週記録するよう勧めています <a class="cite" href="#src-16">[16]</a>。
- 量るときは、デジタルのキッチンスケールを使う方法が紹介されています <a class="cite" href="#src-17">[17]</a>。
- 京都市動物園は、尾が細くなった個体について、2 年で 110 g から 80 g へという体重の推移をもとに、季節による変化ではなく加齢によるものではないかと説明しています <a class="cite" href="#src-18">[18]</a>。一方で、日本の動物病院 A は、やせてきたのを老化と決めつけないよう注意しています（寄生虫や腎臓の病気が隠れていることがあるため） <a class="cite" href="#src-10">[10]</a>。

記録が続いていると、脱皮・冬・繁殖期の一時的な変化なのか、長く続いている傾向なのかを見分けやすくなります。食べなかった日も「拒食」として残しておくと、何回続いているかが分かります。
