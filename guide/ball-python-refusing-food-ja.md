この記事のポイント

- ボールパイソンは、繁殖期・涼しい季節・脱皮の前・抱卵中・迎えた直後など、病気でなくても食べない時期があります。
- 食べないときは、まず温度の勾配、シェルター、静かさ、餌の温め方といった飼育環境を確かめます。
- 様子を見る目安は資料によって数週間から数か月まで分かれます。判断の軸は日数より体重の推移と、口・呼吸・吐き戻し・元気などのサインです。
</div>

## ボールパイソンは拒食が多いヘビ

米国の動物病院チェーン VCA の獣医師は、食欲がない・食べるのを拒む状態になりやすい種としてボールパイソンを挙げています <a class="cite" href="#src-1">[1]</a>。英国の動物福祉団体 RSPCA も、ボールパイソンは餌を拒むことで知られていると書いています <a class="cite" href="#src-2">[2]</a>。

動物病院の飼育シートには、ボールパイソンは好き嫌いがあり数週間続けて食べないこともあるが、普段どおりに動いていて体重が減っていなければ心配しなくてよい、とあります <a class="cite" href="#src-3">[3]</a>。

長く食べなくても耐えられる仕組みも研究されています。ボールパイソンを含む 3 種のヘビに 168 日間餌を与えなかった実験では、どの種も絶食に耐え、安静時の代謝を最大 72% 下げていました <a class="cite" href="#src-4">[4]</a>。ただし、これは実験の条件で、「何日までなら安全」という基準ではありません。

## 病気でなくても食べない、よくある理由

### 繁殖期（特に成熟したオス）

エキゾチック動物の病院の資料は、オスが 10 月から 2 月の繁殖期に食べなくなるのは異常ではないとしています <a class="cite" href="#src-5">[5]</a>。獣医師の Q&A でも、成体は冬の繁殖期によく食べなくなると書かれています <a class="cite" href="#src-6">[6]</a>。

### 涼しい季節

冬に食べなくなる個体がいて、温度が変わっていなければ日照時間が短くなったことが関係しうる、と獣医師の Q&A は説明しています。体重が大きく減らず、やせこけず、口を開けた呼吸やよだれが多いといったサインがなければ心配はなく、晩冬から春に自分から食べ始めるはずだとしています <a class="cite" href="#src-7">[7]</a>。

- ボールパイソンは冬眠しません <a class="cite" href="#src-7">[7]</a>。RSPCA は、拒食がブルメーション（涼しい時期の省エネ状態）に関係しているように見えることがあっても、ブルメーションを促してはいけないとしています <a class="cite" href="#src-2">[2]</a>。
- 季節の拒食では体重があまり落ちない、と国内のボールパイソン専門店 <a class="cite" href="#src-8">[8]</a> やヘビの飼育・繁殖サイト <a class="cite" href="#src-9">[9]</a> は書いています。

### 脱皮の前

脱皮の前は体の色がくすみ、目が青白く濁り、食欲が落ちます <a class="cite" href="#src-10">[10]</a>。おなかがピンクがかり、たいてい食べない、とする動物病院の資料もあります <a class="cite" href="#src-3">[3]</a>。VCA も、脱皮に伴う拒食は正常なことがあるとしています <a class="cite" href="#src-1">[1]</a>。

### 抱卵中・成熟したメス

VCA の獣医師は、抱卵（卵を持っている状態）で食べないことがあり、健康な抱卵個体は食べなくても元気で反応がよいはずだとしています。元気がない・弱っている・反応が鈍いときは、すぐに爬虫類に詳しい獣医師の診察を受けるよう書いています <a class="cite" href="#src-1">[1]</a>。ReptiFiles は、メスが 800〜1,000 g ほどに育ったころ急に食べなくなる時期を「The Wall」と呼び、給餌の間隔を空けて量を減らすよう勧めています <a class="cite" href="#src-11">[11]</a>。

### 迎えた直後・環境が変わった直後

- VCA は、環境に由来する拒食の原因で最も多いのは、新しい環境・変わった環境のストレスだとしています <a class="cite" href="#src-1">[1]</a>。
- 爬虫類両生類獣医師会（ARAV）の資料は、迎えたばかりのヘビを 1〜2 週間そっとしておくよう勧めています <a class="cite" href="#src-12">[12]</a>。RSPCA も、最初の 1 週間は不要に触らないよう書いています <a class="cite" href="#src-2">[2]</a>。
- 大きいケージに移してから食べなくなった例について、獣医師の Q&A は、保温器具が前のままでケージ全体が寒くなっていないかをまず疑うよう書いています <a class="cite" href="#src-6">[6]</a>。

### 触りすぎ・餌の変化

- よく触っているなら、食べるようになるまで触るのをやめる <a class="cite" href="#src-11">[11]</a> <a class="cite" href="#src-6">[6]</a>。RSPCA は、給餌後 48 時間は触らないよう勧めています（吐き戻すことがあるため） <a class="cite" href="#src-2">[2]</a>。
- マウスとラット、冷凍と生き餌のどちらかを好む個体がいます <a class="cite" href="#src-11">[11]</a>。獣医師の Q&A は、いつもと同じ仕入れ先・同じ種類の餌かを確かめるよう書いています（白いマウスと茶色いマウスの違いまで） <a class="cite" href="#src-6">[6]</a>。与える人が変わって餌の大きさが変わると食べないことがある、とする国内の獣医師のコラムもあります <a class="cite" href="#src-13">[13]</a>。

## まず確かめたい飼育環境

### 温度の勾配

ケージの中に暖かい場所と涼しい場所の差（温度の勾配）があり、ヘビが自分で選べることが基本です <a class="cite" href="#src-2">[2]</a>。資料ごとの温度は次のとおりです。

| 資料 | 暖かい場所 | 涼しい場所 |
| --- | --- | --- |
| ARAV（獣医師会） <a class="cite" href="#src-12">[12]</a> | ホットスポット 32〜33℃、暖かい側の日中の周囲 27〜29℃ | 約 24℃を下回らない |
| RSPCA（動物福祉団体） <a class="cite" href="#src-2">[2]</a> | ホットスポット 30〜32℃ | 24〜26℃ |
| ReptiFiles（飼育ガイド） <a class="cite" href="#src-14">[14]</a> | 暖かいシェルター 30〜32℃ | 涼しいシェルター 22〜27℃ |
| PetMD（獣医師の執筆） <a class="cite" href="#src-15">[15]</a> | 約 35℃ | 約 26℃ |

値は資料によって違いますが、共通しているのは、暖かい側と涼しい側の両方を温度計で実測して確かめることです <a class="cite" href="#src-2">[2]</a>。ReptiFiles は、温度や湿度がずれると食べなくなることがあると書いています <a class="cite" href="#src-14">[14]</a>。

### 湿度・シェルター・静かさ

- 湿度の目安は資料によって 40〜80% と幅があります <a class="cite" href="#src-12">[12]</a> <a class="cite" href="#src-15">[15]</a> <a class="cite" href="#src-2">[2]</a>。湿らせた水苔などを入れたシェルターを用意する <a class="cite" href="#src-2">[2]</a> <a class="cite" href="#src-5">[5]</a>、脱皮の時期は湿度を上げる <a class="cite" href="#src-15">[15]</a>、という点は多くの資料で共通しています。
- シェルターは暖かい側と涼しい側に少なくとも 1 つずつ置き、とぐろを巻いたときに体が壁に触れるくらいの、ぴったりした大きさにします <a class="cite" href="#src-16">[16]</a> <a class="cite" href="#src-2">[2]</a> <a class="cite" href="#src-5">[5]</a>。
- RSPCA は、隠れる物の少ない広く開けた空間ではストレスを感じるとして、隠れる物を多く置くよう勧めています <a class="cite" href="#src-2">[2]</a>。国内の獣医師のコラムは、ケージを揺らす、近くで工事があるといった振動も原因になりうると書いています <a class="cite" href="#src-13">[13]</a>。

### 餌の温め方

- ReptiFiles は、冷凍の餌を前の晩に冷蔵庫で解凍し、与える 15〜30 分前に袋ごとお湯に沈めて約 37〜38℃にしてから与えるよう書いています <a class="cite" href="#src-17">[17]</a>。
- ボアやパイソンの仲間は熱を感じる器官で餌を探すので、解凍後に冷めてしまうと興味を示さない、と国内の獣医師のコラムは説明しています <a class="cite" href="#src-13">[13]</a>。
- ARAV の資料は、生きた餌を避けるよう勧めています <a class="cite" href="#src-12">[12]</a>。生き餌を試す場合も、目を離さないよう書く資料があります <a class="cite" href="#src-17">[17]</a>。

## 給餌の間隔と餌の大きさ

| 資料 | 幼い個体 | 成体 |
| --- | --- | --- |
| PetMD（獣医師の執筆） <a class="cite" href="#src-15">[15]</a> | ベビーは 1 日おき、若い個体は週 1 回 | 1〜2 週ごと |
| エキゾチック動物の病院 <a class="cite" href="#src-5">[5]</a> | 週 1 回 | 1〜3 週ごと |
| RSPCA（動物福祉団体） <a class="cite" href="#src-2">[2]</a> | 5〜6 日ごと | 7〜14 日ごと（体重による） |

- 餌の大きさは、体重の 10〜15% を目安にする飼育ガイドがあります <a class="cite" href="#src-17">[17]</a>。太さの基準は「体のいちばん太い部分より太くない」 <a class="cite" href="#src-5">[5]</a>、「胴の中ほどの太さと同じくらい」 <a class="cite" href="#src-15">[15]</a>、「いちばん太い部分より少し太い」 <a class="cite" href="#src-2">[2]</a> と分かれます。
- 与えすぎると太りやすいので頻度を調整する、と動物病院の資料は書いています <a class="cite" href="#src-5">[5]</a>。ReptiFiles は、背骨が目立てば足りず、背骨が見えなければ与えすぎと説明しています <a class="cite" href="#src-17">[17]</a>。

## 何週間まで様子を見るか

ここは資料による差が大きいところです。

| 資料 | 目安 |
| --- | --- |
| 国内の獣医師のコラム <a class="cite" href="#src-13">[13]</a> | 2〜3 週間食べないからといって、強制給餌をしなくても問題ない |
| 獣医師の Q&A <a class="cite" href="#src-7">[7]</a> | 冬の拒食は春に戻るはず。春になっても食べなければ爬虫類に詳しい獣医師に診てもらい、新しい便を持っていく |
| 国内のブリーダー直販サイトの記事 <a class="cite" href="#src-18">[18]</a> | 健康な成体なら 2〜3 か月はほとんど命に関わらない。生後 6 か月未満は 1 か月以上で注意。3 か月以上続くなら相談を考える |
| 国内の専門店 <a class="cite" href="#src-8">[8]</a> | 季節の拒食なら、成体は半年以上でも問題ないことがある |
| ブリーダー向け管理ソフトの記事 <a class="cite" href="#src-19">[19]</a> | ほかに問題のない成体で 6 週間続けて拒食したら、懸念を強める目安（「6 週間ルール」） |

「6 週間ルール」について、今回調べた範囲では、出典はブリーダー向けのソフトの販売元の記事だけで、獣医師の資料には見当たりませんでした。元の記事の意味も「6 週間で受診」ではなく、「6 週間を過ぎて体重が減り続けているなら、温度・湿度・ストレス・健康状態を見直す」というものです <a class="cite" href="#src-19">[19]</a>。

季節や繁殖期の拒食は数か月続くこともあり <a class="cite" href="#src-8">[8]</a> <a class="cite" href="#src-18">[18]</a>、日数だけでは決められません。多くの資料は、様子を見てよいかどうかを体重とほかのサインで判断しています。

### 体重の減り方の目安

| 資料 | 目安 |
| --- | --- |
| エキゾチック動物の病院 <a class="cite" href="#src-5">[5]</a> | 体重が 10% を超えて減ったら何かがおかしく、受診が妥当（期間の指定なし） |
| ReptiFiles（飼育ガイド） <a class="cite" href="#src-17">[17]</a> | 10% を超えて減っておらず、ほかに不調がなければ慌てなくてよい（期間の指定なし） |
| 国内のブリーダー直販サイトの記事 <a class="cite" href="#src-18">[18]</a> | 成体で 1 か月に 5% 以上の減少が続いたら相談を考える |

数字は期間の取り方がそろっていないので、1 回の値で決めるより、体重が減り続けているか（グラフの傾き）と、次のサインがないかをあわせて見ます。

## 拒食と一緒に見られたら、相談を考えるサイン

次のようなサインがあるときは、季節や繁殖期のせいだと決めずに、爬虫類を診られる動物病院への相談を考えます。

- 体重が減り続ける、急に減る <a class="cite" href="#src-11">[11]</a> <a class="cite" href="#src-2">[2]</a>
- 口の中や口のまわりの異変（口の中が赤い、唾液がネバネバする、口のまわりが腫れる、膿のようなものが見える） <a class="cite" href="#src-20">[20]</a>
- 呼吸の異変（口を開けた呼吸、ヒューやプツプツという音、鼻や口からの泡） <a class="cite" href="#src-7">[7]</a> <a class="cite" href="#src-21">[21]</a> <a class="cite" href="#src-22">[22]</a>
- 食べた餌を吐き戻す <a class="cite" href="#src-23">[23]</a>
- 元気がない <a class="cite" href="#src-15">[15]</a> <a class="cite" href="#src-22">[22]</a>。抱卵中のメスで、元気がない・弱っている・反応が鈍い <a class="cite" href="#src-1">[1]</a>
- 脱皮の殻や、目を覆う古い皮（アイキャップ）が残っている <a class="cite" href="#src-15">[15]</a> <a class="cite" href="#src-2">[2]</a>
- 便の色・におい・硬さが変わった <a class="cite" href="#src-3">[3]</a>

強制給餌は、獣医師の Q&A でも最後の手段とされています <a class="cite" href="#src-7">[7]</a>。Merck Veterinary Manual も、補助の給餌は獣医師の指示のもとでだけ行うよう書いています <a class="cite" href="#src-23">[23]</a>。自己判断では行わず、相談のうえで決めます。

## 記録で見るポイント

- 体重は、グラム単位で量れるはかりで週 1 回量り、表に付けていくよう勧められています。小さな変化が問題の前触れになるためです <a class="cite" href="#src-6">[6]</a> <a class="cite" href="#src-11">[11]</a>。
- 毎日餌を出し続けるより、間隔を空けて出す方法を紹介する資料があります。国内の飼育者は、若い個体には週 1 回餌を見せ、反応がなければすぐ片付けるようにしたと書いています <a class="cite" href="#src-24">[24]</a>。2〜3 回続けて食べなければ 2〜3 週間空けるのも一つの方法で、そのとき体重の急な減少がないかを確かめる、とする専門店もあります <a class="cite" href="#src-25">[25]</a>。
- 試した日ごとに、餌の種類と大きさ、冷凍か生き餌か、結果（食べた・拒んだ）、体重を残すと、パターンが見えてきます <a class="cite" href="#src-19">[19]</a>。体重を記録していれば、食べていなくても体重が減っていないから大丈夫、と判断できる、と国内の専門店も書いています <a class="cite" href="#src-26">[26]</a>。

あわせて、脱皮の段階（目が濁った日、脱皮が終わった日）や、迎えた日・ケージを動かした日などの出来事も残しておくと、拒食と重なっているかが分かります。受診のときは、新しい便を持っていくよう獣医師の Q&A は勧めています <a class="cite" href="#src-7">[7]</a>。記録もそのまま見せられます。
